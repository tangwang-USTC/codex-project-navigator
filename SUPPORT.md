# Support

Use [GitHub Issues](https://github.com/tangwang-USTC/codex-project-navigator/issues) for installation problems, compatibility reports, and feature requests.

Before opening an issue, include the VS Code version, official `openai.chatgpt` extension version, Codex Project Navigator version, operating system, and reproducible steps. Do not post tokens, credentials, private thread contents, scientific data, or other secrets.

Security-sensitive reports must use [private vulnerability reporting](https://github.com/tangwang-USTC/codex-project-navigator/security/advisories/new), not a public issue.
